Overview: 
This project is an Nginx web server that is deployed to a local Kubernetes cluster using Minikube. The app runs across multiple Kubernetes pods and is exposed through a Kubernetes Service so that it can be accessed by a web browser.

This project also demonstrates Kubernetes features such as: replica management, scaling, service networking, and self-healing.

Technologies used: Kubernetes, Minikube, Docker, kubectl, Nginx, YAML, Linux
